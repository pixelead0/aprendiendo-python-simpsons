# 🎓 Learning Resources - Aprende Python con Los Simpson

Esta carpeta contiene recursos de aprendizaje detallados que complementan los módulos del curso. Cada archivo profundiza en conceptos específicos con ejemplos prácticos y ejercicios.

## 📚 Recursos Disponibles

### Módulo 1: Introducción a la programación
- **[01_variables_y_tipos.md](./01_variables_y_tipos.md)** - Variables, tipos de datos básicos, f-strings, entrada/salida, comentarios
- **Referencias**: Bart Simpson, Homer, Lisa, Ned Flanders

### Módulo 2: Condicionales y lógica
- **[02_condicionales_y_logica.md](./02_condicionales_y_logica.md)** - if, elif, else, operadores lógicos, validación de datos
- **Referencias**: Sr. Burns, empleados de la planta nuclear

### Módulo 3: Condicionales avanzados
- **[03_condicionales_avanzados.md](./03_condicionales_avanzados.md)** - Condicionales anidados, operadores lógicos complejos
- **Referencias**: Decisiones complejas de Los Simpson

### Módulo 4: Bucles y errores
- **[04_bucles_y_errores.md](./04_bucles_y_errores.md)** - Bucles for/while, manejo de errores try/except, break/continue
- **Referencias**: Homer, donas, intentos fallidos

### Módulo 5: Git y control de versiones
- **[05_git_control_versiones.md](./05_git_control_versiones.md)** - Git, GitHub, control de versiones, ramas, comandos
- **Referencias**: Rivalidad Springfield vs Shelbyville

### Módulo 6: Funciones y organización
- **[06_funciones_organizacion.md](./06_funciones_organizacion.md)** - Funciones, parámetros, retorno, organización de código
- **Referencias**: Lisa Simpson, inteligencia, organización

### Módulo 7: Listas, tuplas y diccionarios
- **[07_listas_tuplas_diccionarios.md](./07_listas_tuplas_diccionarios.md)** - Estructuras de datos, listas, tuplas, diccionarios
- **Referencias**: Moe Szyslak, bar, organización

### Módulo 8: Clases y objetos
- **[08_clases_objetos.md](./08_clases_objetos.md)** - Programación Orientada a Objetos, clases, herencia, encapsulación
- **Referencias**: Maggie Simpson, silencio, inteligencia

### Módulo 9: Módulos, paquetes y orden
- **[09_modulos_paquetes_orden.md](./09_modulos_paquetes_orden.md)** - Módulos, paquetes, organización de código, importación
- **Referencias**: Ned Flanders, orden, organización

## 🎯 Cómo usar estos recursos

### Para estudiantes
1. **Completa el módulo** correspondiente en `slides/`
2. **Lee la documentación** detallada en `learning_resources/`
3. **Practica** con los ejercicios incluidos
4. **Experimenta** con los ejemplos de código
5. **Disfruta** las referencias específicas de Los Simpson

### Para instructores
1. **Usa los ejemplos** como material de apoyo
2. **Adapta los ejercicios** según el nivel de la clase
3. **Referencia los recursos** para explicaciones más profundas
4. **Aprovecha** las referencias humorísticas para mantener el interés

## 📖 Estructura de cada recurso

Cada archivo de learning resource incluye:

1. **Introducción** - ¿Qué es el concepto?
2. **Conceptos básicos** - Explicación clara y progresiva
3. **Ejemplos de código** - Código funcional y comentado
4. **Ejemplo práctico** - Aplicación real del concepto
5. **Buenas prácticas** - Consejos para escribir mejor código
6. **Errores comunes** - Qué evitar y cómo solucionarlo
7. **Ejercicios prácticos** - Para practicar lo aprendido
8. **Recursos adicionales** - Enlaces y referencias útiles
9. **Referencias de Los Simpson** - Episodios y frases específicas

## 🛠️ Tecnologías y herramientas

- **Python 3.x** - Versión actual del lenguaje
- **Markdown** - Formato de documentación
- **Ejemplos ejecutables** - Todo el código puede ejecutarse directamente
