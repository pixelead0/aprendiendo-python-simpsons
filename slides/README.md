## Cómo usar

1. **Abre cualquier módulo** en tu editor de texto favorito
2. **Lee el contenido** siguiendo el orden lógico (01 → 02 → 03 → 04 → 05 → 06 → 07 → 08)
3. **Ejecuta el código** Python que encuentres
4. **Completa los mini retos** para practicar
5. **Disfruta las referencias** específicas de Los Simpson con frases exactas
6. **Consulta los recursos** en `../learning_resources/` para más detalles
