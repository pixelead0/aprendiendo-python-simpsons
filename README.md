# Aprende Python con Los Simpson

Un curso de programación en Python con el estilo único de Los Simpson.

## Estructura del proyecto

```
python_simpsons/
├── slides/                    # Módulos del curso
│   ├── 01_introduccion_programacion.md
│   ├── 02_condicionales_logica.md
│   ├── 03_bucles_errores.md
│   ├── 04_git_control_versiones.md
│   └── README.md
├── learning_resources/        # Recursos de aprendizaje detallados
│   ├── 01_variables_y_tipos.md
│   ├── 02_condicionales_y_logica.md
│   ├── 03_condicionales_avanzados.md
│   ├── 04_bucles_y_errores.md
│   ├── 05_git_control_versiones.md
│   └── README.md
├── readme_technical.md        # Especificaciones técnicas del curso
└── README.md
```

## Cómo usar

1. **Leer los módulos**: Abre cualquier archivo en `slides/` con tu editor favorito
2. **Estudiar en detalle**: Consulta los recursos en `learning_resources/` para más profundidad
3. **Practicar**: Ejecuta el código Python que encuentres
4. **Disfrutar**: Aprende con las referencias humorísticas de Los Simpson

## Características

- ✅ **Formato Markdown puro** - Sin dependencias externas
- ✅ **Código Python ejecutable** - Listo para probar
